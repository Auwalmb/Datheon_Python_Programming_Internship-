About This Repository

This repository contains Python projects developed as part of my Datheon Python Programming Internship learning activities.

The projects demonstrate my practical understanding of Python programming, problem-solving, file handling, data processing, and regular expressions.

Projects

1. Hangman Word Guessing Game

A console-based word guessing game in which players guess a hidden word one letter at a time.

Features:
	•	Random word selection
	•	Six incorrect guesses allowed
	•	ASCII hangman illustrations
	•	Tracking of guessed letters
	•	Prevention of duplicate guesses
	•	Option to play again

File: Task_1_Hangman/hangman.py

2. Stock Portfolio Performance Tracker

A Python program that calculates stock portfolio performance using sample stock prices.

Features:
	•	Calculates total investment
	•	Calculates current portfolio value
	•	Determines profit or loss
	•	Calculates percentage returns
	•	Exports portfolio results to a CSV file

Note: The stock prices are sample data and are not live market prices.

File: Task_2_Stock_Portfolio/portfolio_tracker.py

3. Automated File Organizer

A Python program that organizes files into folders based on their file extensions.

Features:
	•	Uses os.scandir() to scan files
	•	Uses shutil.move() to move files
	•	Categorizes documents, images, videos, archives, and code
	•	Creates destination folders automatically
	•	Avoids overwriting files with duplicate names
	•	Reports successful operations and errors

The included demonstration uses temporary sample files.

File: Task_3_File_Organizer/file_organizer.py

4. Rule-Based Interactive Terminal Assistant

An interactive Python assistant that responds to user input using keywords and regular expressions.

Features:
	•	Greeting responses
	•	Business-hours information
	•	Service information
	•	Basic contact-related responses
	•	Current-time response
	•	Help commands
	•	Exit commands
	•	Fallback responses for unknown questions

File: Task_4_Terminal_Assistant/assistant.py

Technologies Used
	•	Python 3
	•	Random module
	•	CSV module
	•	Operating system file handling (os)
	•	File movement (shutil)
	•	Regular expressions (re)
	•	Date and time handling (datetime)

How to Run the Projects
	1.	Install Python 3 on your computer.
	2.	Clone or download this repository.
	3.	Open a terminal in the project directory.
	4.	Run the desired Python file.

Example: 
python Task_1_Hangman/hangman.py

For the other projects, replace the file path with the appropriate project path.

Requirements: Python 3. No additional third-party packages are required.
